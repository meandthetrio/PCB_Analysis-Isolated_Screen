## Verdict summary
- **The join is clean.** 141 production-BOM designators ↔ 141 schematic symbols ↔ 141 board footprints, all three-way; the 9 schematic+board parts off the BOM (FD1–FD3, H1–H4, LOGO1, QR1) all carry `exclude_from_bom` in both schematic and board; zero phantom, PCB-only, schematic-only or duplicate designators; zero DNP anywhere. The Rev4 CDN sheet carries the same 141 designators plus **D6**, which does not exist on the Rev3 board (PD-P4-06, PD-P4-02).
- **Every SMD part is on the BOM and every paste opening maps to it:** 286 F.Paste flashes in the session plot and in the 2025-12-10 production Gerber, 286/286 matched to the 115 SMD BOM parts, 0 unmatched, no B.Paste (PD-P4-08). The 26 through-hole parts are on the BOM too (`Assembly = PTH` in the CDN sheet) (PD-P4-09).
- **The one build-relevant defect is in the production BOM's format, not its content:** line 10 is `10UF | C15,C18,C19,C26 | Capacitor_SMD:CP_Elec_4x5.8,Capacitor_SMD:C_0805_2012Metric` — one line, four designators, **two footprints**, no quantity — because the Pedal jobset groups by Value only and the value is written `10uF` on eight electrolytics and `10UF` on two electrolytics plus two 0805 MLCCs. Only the hand-curated Rev4 sheet says which is which (PD-P4-01).
- **Documentation drift:** the Rev3 repo's README links a Rev4 BOM, and its "Hardware Reference" switch designators (SW3/SW4 tactile, SW2/SW6 toggles) are the **Rev1** designators, not what the Rev3 silkscreen prints (SW4/SW5 tactile, SW2/SW3 toggles) (PD-P4-02).
- Same procurement-sheet patterns as the Eurorack kit: generic substitutes under original-part CPNs with `Sub OK = NO` (D5/D6 B5817WS for NSR1020MW2T3G, HXY USBLC6-2SC6, HOAUC Type-C on GCT's USB4110 footprint), `Unknown Manufacturer` on two lines, a VPN cell holding an MPN, string-sorted designators (PD-P4-03/04); and the same Rev1 leftovers in the project folder — here they are the repo's own history (stray Rev1 CSV, `…-Rev1_*.kicad_sch` sheet files inside the Rev3 project, a vim swap file with the author's home path, lib-table entries for relay/USB libraries the Rev3 board no longer uses) (PD-P4-05).
- **Seed 3 representation is identical to the Eurorack kit**: direct through-hole `A1`, stock KiCad `Module:Electrosmith_Daisy_Seed` footprint matching the datasheet landing pattern, listed on the CDN BOM as `Seed3 / SOM / Assembly PTH` (PD-P4-10).
